# AutoClicker — 多步骤宏工具

Windows 桌面自动化点击工具，支持多步骤宏编排、录制回放、图片识别定位与游戏级底层输入模拟。基于 Python + Tkinter 构建，开箱即用。

## 功能特性

### 多步骤宏编排
- 支持 **左键点击 / 右键点击 / 等待延时 / 键盘按键 / 识图点击 / 截图保存 / 条件分支** 七种步骤类型
- 步骤可自由添加、删除、上移、下移、复制、编辑
- 支持有限次循环与无限循环，可设置循环次数
- 右键菜单快速设置 **仅首次执行**、**执行后等待**、**搜索区域**、**滚轮搜索**

### 条件分支
- 快速扫描图片，满足条件则执行子步骤，否则跳过
- 子步骤支持：截图选点、match 位置点击、识图点击、等待、按键
- 未配置子步骤时自动点击识别位置
- 适用于处理随机弹窗、对话框、通知等偶发 UI 元素

### 录制回放
- 一键录制鼠标点击与键盘操作，自动生成宏步骤
- 支持录制过程中暂停（F2）与恢复
- 录制事件自动转换为带等待间隔的步骤序列

### 窗口绑定
- 绑定指定窗口，点击操作定向到目标窗口
- 支持探测子窗口，适用于模拟器等多层窗口结构
- 提供 PostMessage 与 SendInput 两种点击方式

### 图片识别
- 截取屏幕区域作为模板，运行时自动匹配并点击
- **可调匹配精度**（0.50 ~ 0.99），默认 0.90，适合有汉字的图片
- 点击后检测图片是否消失，验证操作是否生效
- 支持中文文件名（通过 np.fromfile + cv2.imdecode）

### 视觉框选
- **搜索区域**：拖拽框选识图搜索范围，避免全屏扫描
- **截图范围**：截图前先框选大范围，再精确截图
- **窗口跟随**：绑定窗口时自动存为相对坐标，窗口移动后区域自动跟随
- **滚轮位置**：点击选点或框选范围，鼠标移到目标位置自动滚动

### 滚轮搜索
- 识图找不到时自动滚动页面搜索（适合列表/长页面）
- 录制模式：框选滚动范围 → 倒计时 3 秒 → 实际滚动一次 → 记录方向和幅度
- 使用 SendInput 底层 API 发送滚轮，兼容游戏和模拟器
- 连续滚动后移走鼠标，避免遮挡目标影响识别

### 拟人模式
- 贝塞尔曲线鼠标轨迹模拟真人移动路径
- 按压时长随机化（默认 30-120ms）
- 等待时间波动（默认 ±30%）
- 随机像素偏移（可配置偏移范围）

### Game Mode
- SendInput 扫码级输入模拟
- PostMessage 后台静默点击
- Interception 驱动级输入（需额外安装）
- Scancode 直接发送，绕过部分游戏按键检测

### 可视化标记
- 点击位置实时显示带编号的圆圈标记（①②③…）
- 标记支持鼠标穿透，不影响图片识别
- 运行宏时自动清除标记，确保屏幕干净

### 配置管理
- 保存 / 加载 / 删除命名配置方案
- 支持导出为 JSON 文件与从文件导入
- 导入时自动修复图片路径（按文件名在 screenshots/ 目录查找）

## 快捷键

| 快速键 | 功能 |
|--------|------|
| F9 | 开始执行 |
| F10 | 停止执行 / 停止录制 |
| F2 | 暂停 / 恢复录制 |

## 右键菜单

| 选项 | 说明 |
|------|------|
| 编辑步骤 | 修改步骤参数（超时、精度、坐标等） |
| 仅首次执行 | 第二轮循环起跳过该步骤 |
| 框选搜索区域 | 拖拽框选识图范围（支持窗口跟随） |
| 设置滚轮搜索 | 框选范围 + 录制滚轮（识图步骤专用） |
| 设置执行后等待 | 步骤执行完后等待指定毫秒 |
| 在前面/后面插入 | 插入等待、按键、条件分支 |
| 复制 / 删除 | 复制或删除步骤 |

## 环境要求

- Windows 10/11 64-bit
- Python 3.9+

## 安装依赖

```bash
pip install pyautogui opencv-python pynput pywin32 numpy
```

| 依赖 | 用途 | 必需 |
|------|------|------|
| pyautogui | 鼠标控制、截图 | 推荐 |
| opencv-python | 图片识别匹配 | 识图功能需要 |
| numpy | 图片读取（中文路径支持） | 识图功能需要 |
| pynput | 热键监听、录制 | 录制功能需要 |
| pywin32 | 窗口绑定、PostMessage | 窗口绑定需要 |

> 以上依赖均为可选，未安装时对应功能自动降级，不影响其他功能使用。

## 运行

```bash
# 直接运行
python autoclicker.py

# 以管理员身份运行（解决模拟器/游戏点击无效问题）
# 右键 → 以管理员身份运行
```

## 打包为 EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name AutoClicker autoclicker.py
# 生成文件位于 dist/AutoClicker.exe
```

## 使用流程

### 基础点击宏

1. 点击 **+ 左键** 或 **+ 右键**，3 秒内将鼠标移到目标位置
2. 添加 **+ 等待** 设置步骤间延时
3. 设置循环次数，点击 **开始 (F9)**

### 录制回放

1. 点击 **⏺ 录制**，倒计时 3 秒后开始
2. 执行需要录制的操作（鼠标点击、键盘按键）
3. 按 **F10** 停止录制，步骤自动填充到列表

### 识图点击

1. 点击 **+ 截图**，拖动选择目标图片区域
2. 设置识别超时时间和匹配精度（汉字图片建议 0.90~0.95）
3. 可选：框选搜索区域、设置滚轮搜索
4. 运行时自动在屏幕上查找匹配图片，找到后点击

### 条件分支

1. 点击 **+ 条件**，选择条件图片
2. 设置扫描超时（默认 0.5 秒）
3. 可选：框选搜索区域
4. 配置子步骤（截图选点 / match 点击 / 识图点击 / 等待 / 按键）
5. 不配子步骤则自动点击识别位置

### 窗口绑定（模拟器/游戏）

1. 在窗口列表中选择目标窗口，点击 **确定选择**
2. 勾选 **启用窗口绑定**
3. 选择点击方式：PostMessage（后台）或 SendInput（前台）
4. 模拟器场景建议开启 **Game Mode**

## 注意事项

- **管理员权限**：操作模拟器或以管理员运行的程序时，需以管理员身份启动本工具
- **图片识别**：截图模板需保持与运行时屏幕分辨率一致，分辨率变化后需重新截图
- **Game Mode**：Interception 驱动需从 [oblitum/interception](https://github.com/oblitum/interception) 单独安装
- **随机偏移**：偏移范围过大会影响点击精度，建议 2-5px
- **拟人模式**：会显著降低执行速度，仅在需要模拟真人操作时开启
- **安全停止**：任何时候按 F10 可立即停止，鼠标移至屏幕左上角可触发 pyautogui failsafe（需未禁用）
