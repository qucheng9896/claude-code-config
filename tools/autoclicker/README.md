# 阴阳师痒痒鼠爬塔助手（AutoClicker）— 多步骤宏工具

Windows 桌面自动化点击工具，支持多步骤宏编排、录制回放、图片识别定位与游戏级底层输入模拟。基于 Python + Tkinter 构建，采用阴阳师风格深色 UI，可打包为单文件 EXE 直接使用。

## 快速开始

```bash
# 直接用打包好的 EXE（无需安装环境）
dist/阴阳师痒痒鼠爬塔助手.exe
# 以管理员身份运行（解决模拟器/游戏点击无效问题）

# 或从源码运行
python autoclicker.py
```

## 功能特性

### 多步骤宏编排
- 支持 **左键点击 / 右键点击 / 等待延时 / 键盘按键 / 识图点击 / 运行时截图 / 条件分支** 七种步骤类型
- 步骤可自由添加、删除、上移、下移、复制、编辑
- 支持有限次循环与无限循环，可设置循环次数
- 右键菜单快速设置 **仅首次执行**、**执行后等待**、**搜索区域**、**滚轮搜索**

### 截图与识图
- **+ 截图**：框选截图后选择用途（识图点击 / 运行时截图保存）
- **📁 从文件夹选图**：直接选择已有图片配置识图点击
- **可调匹配精度**（0.50 ~ 0.99），默认 0.90，适合有汉字的图片
- 点击后检测图片是否消失，验证操作是否生效
- 支持中文文件名（通过 np.fromfile + cv2.imdecode）

### 条件分支
- 快速扫描图片，满足条件则执行子步骤，否则跳过
- 子步骤支持：截图选点、match 位置点击、识图点击、等待、按键
- 未配置子步骤时自动点击识别位置
- 适用于处理随机弹窗、对话框、通知等偶发 UI 元素

### 录制回放
- 一键录制鼠标点击与键盘操作，自动生成宏步骤
- 支持录制过程中暂停（F2）与恢复
- 录制事件自动转换为带等待间隔的步骤序列

### 窗口绑定
- 绑定指定窗口，点击操作定向到目标窗口
- 支持探测子窗口，适用于模拟器等多层窗口结构
- 提供 PostMessage 与 SendInput 两种点击方式

### 拟人模式（总开关）
- **一键开启**：自动启用随机偏移 + 随机按压时长 + 随机步骤间隔
- 贝塞尔曲线鼠标轨迹模拟真人移动路径
- 按压时长随机化（默认 50-180ms，可调）
- 步骤间随机间隔（默认 100-300ms，可调）
- 随机像素偏移（可配置偏移范围）
- 每次点击的时间与位置都在变化，接近真人操作节奏

### Game Mode
- SendInput 扫码级输入模拟
- PostMessage 后台静默点击
- Interception 驱动级输入（需额外安装）
- Scancode 直接发送，绕过部分游戏按键检测

### 可视化标记
- 点击位置实时显示带编号的圆圈标记（①②③…），支持鼠标穿透
- 勾选"标记"可立即显示所有步骤位置，一键清除

### 配置管理
- 保存 / 加载 / 删除命名配置方案
- 支持导出为 JSON 文件与从文件导入
- 导入时自动修复图片路径（按文件名在 screenshots/ 目录查找）

## 快捷键

| 快速键 | 功能 |
|--------|------|
| F9 | 开始执行 |
| F10 | 停止执行 / 停止录制 |
| F2 | 暂停 / 恢复录制 |

## 环境要求

- Windows 10/11 64-bit
- Python 3.9+（仅从源码运行时需要）

## 安装依赖

```bash
pip install pyautogui opencv-python pynput pywin32 numpy pyinstaller
```

| 依赖 | 用途 | 必需 |
|------|------|------|
| pyautogui | 鼠标控制、截图 | 推荐 |
| opencv-python | 图片识别匹配 | 识图功能需要 |
| numpy | 图片读取（中文路径支持） | 识图功能需要 |
| pynput | 热键监听、录制 | 录制功能需要 |
| pywin32 | 窗口绑定、PostMessage | 窗口绑定需要 |

> 以上依赖均为可选，未安装时对应功能自动降级，不影响其他功能使用。

## 打包为 EXE

```bash
pyinstaller --onefile --windowed --name AutoClicker autoclicker.py \
  --icon=app_icon.ico --exclude-module PyQt5 --exclude-module sip
# 生成文件位于 dist/AutoClicker.exe
```

> 打包时 `--exclude-module PyQt5` 可减小体积约 30MB（PyQt5 是依赖的隐式引入，本工具用不到）。
> 窗口标题栏/任务栏图标已内嵌进程序，单文件分发即可显示。

```
├── screenshots/   # 截图图片

```

## 注意事项

- **管理员权限**：操作模拟器或以管理员运行的程序时，需以管理员身份启动本工具
- **图片识别**：截图模板需保持与运行时屏幕分辨率一致，分辨率变化后需重新截图
- **Game Mode**：Interception 驱动需从 [oblitum/interception](https://github.com/oblitum/interception) 单独安装
- **随机偏移**：偏移范围过大会影响点击精度，建议 2-5px
- **拟人模式**：会降低执行速度，仅在需要模拟真人操作时开启
- **安全停止**：任何时候按 F10 可立即停止
